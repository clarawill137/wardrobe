# 👗 Гардероб для SillyTavern

Шкаф вещей, коллекция образов и трекер «кто во что одет». Работает в групповых чатах.

- **На них** — что надето на каждом персонаже, что снято и лежит рядом; пометки (расстёгнута, мокрая…).
- **Шкаф** — вещи текстом, промптом образа или фото: ИИ раскладывает образ на отдельные вещи.
- **Образы** (1.8) — коллекция полных образов на весь экран, как каталог нарядов:
  - сверху кнопка на каждого персонажа (и «✦» — все), под ней разделы: Офис, Вечернее, Спортивное (видны всегда),
    Повседневное, Дом и сон, Бельё, Миссия и свои; список разделов — в ⚙;
  - карточки в две колонки: картинка целиком (не обрезается), «Надеть», ⧉ скопировать промт, 👕 — что внутри;
    свайп по картинке листает её версии (новая картинка не стирает старые);
  - **＋ Образ** — загрузить фото образа и/или вставить готовый промт: ИИ за кадром считает промт, придумает название,
    выберет раздел, разложит на вещи, положит их в шкаф (такие же вещи, что уже есть, — не дублирует) и соберёт образ;
    по желанию сразу нарисует образ на персонаже (лицо из рефов) и вещи для шкафа;
  - у персонажа — только его образы; общие (без владельца) — отдельным блоком внизу, тап по «общий» — отдать персонажу;
    старые комплекты без владельца (прежний конструктор ставил «общее») при первом открытии разбираются сами:
    по первому слову названия («Хеди, осень» → Хеди) или по владельцам вещей (1.8.1);
  - старые образы без раздела — кнопка «Разложить по разделам (ИИ)»;
  - надеть несколько (бельё + основной) — надень по очереди: заменяются только вещи тех же типов; «Переодеть полностью» —
    в карточке образа.
- **📌 Закреплённые вещи** — кольца, пирсинг, жетоны: не снимаются при смене образа и при «Раздеть».
- **Костюмер** — модель через профиль подключения после каждого сообщения замечает, кто что снял или надел. Свайпы и удаления откатывают изменения.
- **Причёски и макияж** — отдельные категории: тоже надеваются, снимаются и отслеживаются.
- **Картинки** — у образов и у вещей шкафа свой стиль (1.8.3): образы по умолчанию — «Масло, полуреализм» (живопись
  маслом, тот же человек дважды на светлом фоне — в полный рост и крупнее в три четверти, портрет 2:3), вещи — прежний
  карандашный лукбук. Акварель, каталог, аниме, иконки и свой стиль — выбором в 🎨 на странице образов (два ряда:
  «Образы» и «Вещи в шкафу») или в ⚙. Лицо — из рефов sillyimages/SLAY или аватарки. Рисует через
  SLAY / sillyimages (Atlas Cloud, Naistera, OpenRouter, Gemini, xAI, OpenAI) или свой ключ. У Atlas (1.8.5) — все рисовалки
  SLAY: Nano Banana, Grok, GPT Image 2 / 2.5, Seedream 5.0 / 5.5, FLUX 3, MAI-Image 2.6, Qwen Image 3.0, Wan 2.7,
  Grok Imagine 2.0, Midjourney V8.2, Flux Kontext (и с LoRA из SLAY), а по тексту — Flux Dev, Grok, Midjourney, Krea 2 Turbo.
  Лицо по рефу держат только модели с рефами; проверка запросов — `node tools/atlas-test/atlas.mjs`.
- **Состав образа** (1.8.3): вещи по разделам (подзаголовки и чипы «Обувь», «Низ»…); у образа с владельцем — только его
  вещи, у общего — чипы людей.
- Основная модель перед каждым ответом получает записку, кто во что одет.
- **Шкаф по облику** (1.7, если стоит ядро «Священный таймлайн»): один человек в разные эпохи — разные облики, и шкаф
  у каждого свой. Вещь и образ запоминают облик владельца; в чате эпохи видно своё и общее, «🕰 Все эпохи» —
  всё сразу. Старые вещи (до эпох) — шкаф облика основной ролки (эпоха мира по умолчанию). Без ядра — всё как раньше.
- **Эпохи до конца** (1.8.2): общее (без владельца) тоже живёт в эпохе — общее из сороковых не всплывает в 2024-м и
  наоборот (старое общее — эпоха мира по умолчанию). Костюмер подбирает только из шкафа этой эпохи; образ, у которого
  разбор нашёл владельца, получает его облик; «Лицо для картинок» в другой эпохе — своё у облика, а рисуя, гардероб
  сначала берёт лицо облика, потом лорбук рефов SLAY (он сам выбирает облик по ядру), потом карточку этой эпохи —
  и только в конце лицо основной ролки. `Wardrobe.setsFor` для Life — строго образы этой эпохи.

- **Эпохи — надёжнее (1.8.7)**: её скрин 23.11 — в группе сороковых коллекция Хеди показывала все 85 образов 2024-го и
  белую аватарку. Теперь: снимок ядра берётся только от этого чата (пока ядро после смены чата его не пересобрало — строка
  «эпоха чата ещё определяется…», образы эпох спрятаны, страница перерисуется сама); облик владельца, которого нет среди
  участников, — по дате чата из Реестра (Наташа 2024-го не всплывает в сороковых); своё без облика — шкаф основной ролки
  (разово разложено); под «Hedy Barlow · N образов» — строка «🕰 эпоха · облик · ещё N — в других эпохах» (тап — «Все
  эпохи»); у образа в окне — **«Эпоха»**: перенести образ в другой облик руками; аватарка в другой эпохе — лицо облика,
  иначе персона или карточка эпохи (не лицо 2024-го).

Для соседей (Life): `Wardrobe.setsFor(кто)` — образы, которые видно в этом чате; `Wardrobe.open('looks', кто)` или
`Wardrobe.openLooks(кто, раздел)` — коллекция образов (старое `open('sets')` тоже открывает её); `Wardrobe.wearSets`,
`Wardrobe.drawSet`, `Wardrobe.cats()`, `Wardrobe.sliceOf(имя)` — облик.

Установка: Расширения → Install extension → `https://github.com/clarawill137/wardrobe`.
Настройки — вкладка ⚙ в самой плашке (нужен профиль подключения для костюмера, для разбора фото — профиль, который видит
картинки). Команды: `/wardrobe` — плашка, `/wardrobe looks` — коллекция образов.
