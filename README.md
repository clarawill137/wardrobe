# 👗 Гардероб для SillyTavern

Шкаф вещей, комплекты и трекер «кто во что одет». Работает в групповых чатах.

- **На них** — что надето на каждом персонаже, что снято и лежит рядом; пометки (расстёгнута, мокрая…).
- **Шкаф** — вещи текстом, промптом образа или фото: ИИ раскладывает образ на отдельные вещи.
- **Комплекты** — собрать из шкафа или сохранить надетое, надеть одной кнопкой.
- **Костюмер** — модель через профиль подключения после каждого сообщения замечает, кто что снял или надел. Свайпы и удаления откатывают изменения.
- Основная модель перед каждым ответом получает записку, кто во что одет.

Установка: Расширения → Install extension → `https://github.com/clarawill137/wardrobe`.
Настройки — вкладка ⚙ в самой плашке (нужен профиль подключения для костюмера). Команда: `/wardrobe`.
