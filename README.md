# 👗 Гардероб для SillyTavern

Шкаф вещей, комплекты и трекер «кто во что одет». Работает в групповых чатах.

- **На них** — что надето на каждом персонаже, что снято и лежит рядом; пометки (расстёгнута, мокрая…).
- **Шкаф** — вещи текстом, промптом образа или фото: ИИ раскладывает образ на отдельные вещи.
- **Комплекты** — собрать из шкафа или сохранить надетое; можно надеть несколько сразу (бельё + основной): заменяются только вещи тех же типов.
- **📌 Закреплённые вещи** — кольца, пирсинг, жетоны: не снимаются при смене комплекта и при «Раздеть».
- **Костюмер** — модель через профиль подключения после каждого сообщения замечает, кто что снял или надел. Свайпы и удаления откатывают изменения.
- **Причёски и макияж** — отдельные категории: тоже надеваются, снимаются и отслеживаются.
- **Картинки** — каждой вещи можно нарисовать иллюстрацию: лукбук на самом персонаже (лицо из рефов sillyimages/SLAY или аватарки), скетч модельера, фото из каталога, аниме, иконка или свой стиль, дорисовать весь шкаф одной кнопкой и нарисовать обложку комплекта. Рисует через SLAY / sillyimages (Atlas Cloud, Naistera, OpenRouter, Gemini, xAI, OpenAI) или свой ключ.
- Основная модель перед каждым ответом получает записку, кто во что одет.
- **Шкаф по облику** (1.7, если стоит ядро «Священный таймлайн»): один человек в разные эпохи — разные облики, и шкаф
  у каждого свой. Вещь и комплект запоминают облик владельца; в чате эпохи видно своё и общее, «🕰 Все эпохи» —
  всё сразу. Старые вещи (до эпох) — шкаф облика основной ролки (эпоха мира по умолчанию). Без ядра — всё как раньше.
  Для соседей: `Wardrobe.setsFor(кто)` — комплекты, которые видно в этом чате, `Wardrobe.sliceOf(имя)` — облик.

Установка: Расширения → Install extension → `https://github.com/clarawill137/wardrobe`.
Настройки — вкладка ⚙ в самой плашке (нужен профиль подключения для костюмера). Команда: `/wardrobe`.
